# 🏠 Casa Dashboard Community v1.1.3

Prima release stabile con configurazione guidata direttamente dalla dashboard.

## ✨ Novità

- popup **Configura le entità** integrato nella dashboard;
- gestione delle **173 associazioni logiche** senza modificare manualmente JSON;
- ricerca per stanza, funzione o chiave;
- suggerimenti delle entity_id presenti nell'istanza Home Assistant;
- salvataggio sicuro nel file Community dedicato;
- entità e funzioni non configurate nascoste automaticamente;
- ambienti e voci menu senza funzioni configurate non vengono visualizzati;
- README arricchito con screenshot reali della Panoramica e della configurazione.

## 🔀 Separazione dalla dashboard personale

La Community continua a utilizzare:

- `custom_components/casa_dashboard_community`
- domain `casa_dashboard_community`
- pannello `casa-dashboard-community`
- `/config/www/casa-dashboard-community-entities.json`

Può quindi convivere con una Casa Dashboard personale basata su `casa_dashboard`.
