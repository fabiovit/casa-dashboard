# Casa Dashboard Community v4.1.1

## 🇮🇹 Italiano

Casa Dashboard Community 4.1.1 migliora la gestione degli sfondi e aggiunge il supporto ai robot rasaerba di Home Assistant.

### Novità
- Selettori colore reali per lo sfondo generale e per le singole stanze
- Sfumature configurabili con due colori e angolo personalizzato
- Migliore leggibilità di card e contenuti sopra fotografie di sfondo
- Corretto lo sfondo stanza durante lo scroll
- Supporto alle entità `lawn_mower`
- Visual dedicato per robot rasaerba
- Comandi Avvia e Ritorna alla base
- Tutti i miglioramenti della serie 4.1 restano inclusi

## 🇬🇧 English

Casa Dashboard Community 4.1.1 improves background customization and adds support for Home Assistant robotic lawn mowers.

### Highlights
- Real color pickers for dashboard and room backgrounds
- Two-color gradients with configurable angle
- Improved readability over photo backgrounds
- Fixed room background behavior while scrolling
- Support for `lawn_mower` entities
- Dedicated robotic mower visual
- Start mowing and dock controls
- All previous v4.1 improvements remain included
