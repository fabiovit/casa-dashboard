# Casa Dashboard Community v2.1.0

## 🌍 Multi-language release

Casa Dashboard Community now includes built-in **Italian / English** interface support.

### New
- 🇮🇹 Italian interface
- 🇬🇧 English interface
- Language selector directly in the dashboard header
- Language preference saved per browser/device
- Casa V1 and Casa V2 both supported
- English translations for Overview, rooms, entity configurator, information, states, weather, energy, EV/wallbox and common controls
- Home Assistant entity names and user-defined room/device names are intentionally preserved

### Compatibility
- Existing 2.0.0 configurations are preserved.
- No entity remapping is required.
- Casa V1 and Casa V2 remain available.
