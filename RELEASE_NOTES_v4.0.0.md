# Casa Dashboard Community v4.0.0

## 🇮🇹 Italiano

Casa Dashboard Community 4.0 porta a release stabile l'attuale generazione Dynamic.

### Novità principali

- Panoramica completamente dinamica
- Stanze configurabili e riordinabili
- Moduli condivisi per Energia solare, EV + Wallbox, Meteo e Allarme
- Vista fotovoltaico avanzata con PV1/PV2, batteria, casa e rete
- Meteo condiviso tra Panoramica e stanze
- EV + Wallbox con console dedicata
- Dati Auto elettrica separati dai dati Wallbox
- Clima, tende, elettrodomestici, sensori e sicurezza con visual dedicati
- Tema chiaro e scuro
- Interfaccia IT / EN
- Supporto responsive desktop e mobile

Questa release consolida tutti i miglioramenti della serie 3.6–3.9 in una nuova base stabile 4.0.

## 🇬🇧 English

Casa Dashboard Community 4.0 promotes the current Dynamic generation to a stable major release.

Highlights include dynamic rooms, reusable Solar / EV + Wallbox / Weather / Alarm modules, advanced solar visualization, dedicated EV and Wallbox presentation, room-specific visuals, light/dark themes and IT/EN support.
