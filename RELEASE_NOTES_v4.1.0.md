# Casa Dashboard Community v4.1.0

## 🇮🇹 Italiano

Casa Dashboard Community 4.1 porta numerosi miglioramenti nati dai test reali della Community.

### Novità principali

- Libreria icone ampliata e visual luci più coerenti con lo stato
- Distinzione corretta tra lampadina e plafoniera
- Filtro dispositivi per stanza nel configuratore
- Foto personalizzate migliorate anche per cover, tapparelle e tende
- Upload immagini da smartphone più robusto
- Migliore gestione dell'orientamento delle foto da mobile
- Posizione di scroll del configuratore mantenuta dopo modifiche e rimozioni
- Rendering delle stanze basato sul tipo e non sul nome
- Sfondo generale e per stanza personalizzabile con colore, sfumatura o immagine
- Panoramica/Home fissa nella barra superiore con stanze scorrevoli
- Visual Auto elettrica migliorato e dati EV non più duplicati
- Supporto grafico per robot aspirapolvere/lavapavimenti
- Dimensione configurabile per le singole entità
- Vista fotovoltaico e batteria più compatta su smartphone

## 🇬🇧 English

Casa Dashboard Community 4.1 introduces a broad set of improvements based on real Community testing.

Highlights include expanded icon support, room filtering, improved custom photos, stronger mobile image handling, persistent configurator scroll position, room rendering independent from room names, custom backgrounds, fixed Home navigation, improved EV presentation, vacuum robot support, per-entity size controls and a denser mobile solar layout.
