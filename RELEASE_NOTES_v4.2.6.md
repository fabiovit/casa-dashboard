# Casa Dashboard Community v4.2.6 - Release Candidate

Final cleanup and consolidated responsive pass based on the tester reports of 31/08 and 01/09/2026.

- One authoritative responsive layer for smartphone/tablet behavior
- Fixed horizontal section headings (no vertical word wrapping)
- Physically compact Overview and room headers on smartphones
- Active States and Electric Vehicle panels readable over custom backgrounds
- Covers/blinds included in Active States
- Active States popup refreshes from actual Home Assistant state changes
- Italian state labels extended; generic toggle labels are Italian in IT mode
- Smart lock uses a single renderer with photo, size, localized state and working controls
- Alexa/media_player uses the standard universal device card
- Climate photos supported without duplicate renderers
- Sensor, robot and mower photos constrained consistently on smartphones
- Photovoltaic and battery visuals reduced for mobile
- Per-room device ordering and live icon preview preserved
- Overview visibility/size configuration and background persistence preserved
- Kiosk mode preserved
- Old release notes, bytecode and stale build debris removed
