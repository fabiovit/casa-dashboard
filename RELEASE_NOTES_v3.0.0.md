# Casa Dashboard Community v3.0.0

## 🇬🇧 English

Casa Dashboard Community 3.0 is a major cleanup and consolidation release.

### Highlights

- Unified backend/frontend versioning.
- Removed stale internal references from older releases.
- Preserved Casa V1 Classic and Casa V2 Dynamic.
- Preserved dynamic rooms and the 173 Community entity mappings.
- Preserved smart device recognition.
- Preserved English / Italian interface support.
- Preserved improved configurator scrolling for large setups.
- Cleaned repository structure and removed obsolete release-note clutter.
- Refreshed bilingual documentation.
- Package validated for HACS distribution.

This release focuses on stability, consistency and a cleaner foundation for future development.
