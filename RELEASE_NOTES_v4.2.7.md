# Casa Dashboard Community v4.2.7

## Native kiosk mode

- `?kiosk=1` now enables Home Assistant native kiosk mode.
- Home Assistant sidebar/menu is hidden while kiosk mode is active.
- Casa Dashboard `Configura`, language switch and Home Assistant menu button are hidden too.
- Leaving the dashboard restores the normal Home Assistant interface.

## Maintenance

- Cleaned the frontend kiosk path and removed obsolete release artifacts.
- Kept the 19-part frontend loader and all v4.2.6 responsive/configuration improvements.
