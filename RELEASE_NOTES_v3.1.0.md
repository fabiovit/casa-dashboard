# Casa Dashboard Community v3.1.0

## 🇬🇧 English

Version 3.1.0 improves the Casa V2 Overview for real Community installations, especially when only a small subset of the 173 optional mappings is configured.

### Improvements

- Global Overview mappings now support a custom **display name**, just like entities inside Casa V2 rooms.
- Naming priority: custom display name → Home Assistant friendly name → Community fallback.

- Overview cards now remain visually complete even with only a few configured Solar / Battery / EV entities.
- Fixed card contrast in Home Assistant light themes.
- Adaptive card grids automatically use the available space.
- Power values are normalized to kW and limited to two decimals.
- Improved formatting for battery, energy, temperature and numeric sensors.
- Wallbox / EV binary states are displayed with readable labels.
- The configuration notice no longer says that configuration is “incomplete”.
- 173 mappings are explicitly described as optional: configure only the functions you actually use.

**Special thanks to Mario Pagano for his feedback and suggestions that helped improve Casa Dashboard Community v3.1.0. 🙏**

## 🇮🇹 Italiano

La versione 3.1.0 migliora la Panoramica Casa V2 nelle installazioni reali della Community, soprattutto quando vengono configurate solo alcune delle 173 associazioni opzionali.

### Miglioramenti

- Le associazioni globali della Panoramica ora possono avere un **nome visualizzato personalizzato**, come le entità delle stanze Casa V2.
- Priorità del nome: nome personalizzato → friendly name Home Assistant → nome Community.


- Le card della Panoramica restano graficamente complete anche con pochi sensori FV / Batteria / EV configurati.
- Corretta la scarsa leggibilità delle card con i temi chiari di Home Assistant.
- Le griglie si adattano automaticamente al numero di informazioni disponibili.
- I valori di potenza vengono normalizzati in kW e limitati a due decimali.
- Migliorata la formattazione di batteria, energia, temperatura e sensori numerici.
- Gli stati binari Wallbox / EV vengono mostrati con descrizioni leggibili.
- Il messaggio non parla più di “configurazione incompleta”.
- Viene chiarito che le 173 associazioni sono opzionali: basta configurare solo le funzioni realmente utilizzate.

**Un ringraziamento speciale a Mario Pagano per i feedback e i suggerimenti che hanno contribuito a migliorare Casa Dashboard Community v3.1.0. 🙏**
